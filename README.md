# Tiny Skies — PC demo

Tiny Skies is a cozy idle game where you run a little airline of birds.

## Install

1. Open the [latest release](https://github.com/Timidis1/tiny-skies-demo/releases/latest) and download **TinySkies-Setup-x.y.z.exe**.
2. Run it. Windows may say "Windows protected your PC" because the demo isn't signed yet: click **More info → Run anyway**.
3. Tiny Skies installs for your Windows user and opens. You'll find it in the Start menu.

The game updates itself: when a new demo build is out, it downloads in the background and asks you to restart. Your progress is kept.

To uninstall, use Windows Settings → Apps → Tiny Skies.

This repository only holds the demo installers.
